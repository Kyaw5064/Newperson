# Newperson — လူသစ် မှတ်တမ်း

စက်ရုံကို လူသစ်ခေါ်ပေးသူအတွက် Android app။ လူသစ်တစ်ယောက်ချင်းရဲ့ ဖုန်းနံပါတ်၊ စာရွက်စာတမ်း၊ အလုပ်ဝင်ရက်၊ အရေးပေါ်ဆက်သွယ်ရန် စတာတွေကို **အမှန်ကန်ဆုံး** မှတ်ထားဖို့ ရေးထားတာပါ။ မြန်မာ / ไทย / English ဘာသာ ၃ မျိုး။

## APK ဒေါင်းလုဒ်
GitHub repo → **Releases** → နောက်ဆုံး version → `Newperson-v1.0.X.apk` ကိုနှိပ်ပြီး ဖုန်းမှာ install လုပ်ပါ။
`main` ကို push လုပ်တိုင်း GitHub Actions က APK အသစ်ကို အလိုအလျောက် build လုပ်ပေးပါတယ် (၁၅–၃၀ မိနစ်ခန့်)။ Actions tab → **Build Android APK** → **Run workflow** နဲ့လည်း လက်နဲ့ run လို့ရပါတယ်။

## ပါဝင်တာများ
- **ဖုန်းနံပါတ် မှန်အောင်**: ထိုင်း (06/08/09 + ၁၀ လုံး) / မြန်မာ (09…) format စစ်ခြင်း၊ နှစ်ခါရိုက် တိုက်စစ်ခြင်း၊ တခြားလူနဲ့ ထပ်နေရင် ချက်ချင်းပြခြင်း၊ ဖုန်းဆက်ပြီး "စစ်ပြီး ✓" အမှတ်အသားလုပ်ခြင်း
- ကိုယ်ရေး၊ ဆက်သွယ်ရန် (ဖုန်း ၂ လုံး၊ LINE၊ Facebook)၊ စာရွက်စာတမ်း (Passport / ပန်းရောင်ကတ် / CI) + သက်တမ်းကုန်ရက်၊ နေရပ်၊ ဌာန / ရာထူး / အဆိုင်း / အလုပ်ဝင်ရက်၊ အရေးပေါ်ဆက်သွယ်ရန်၊ ခေါ်ပေးခ၊ မှတ်ချက်
- အခြေအနေ အဆင့်: ခေါ်ထားဆဲ → အင်တာဗျူး → စာရွက်လုပ်ဆဲ → အလုပ်ဝင်ပြီ / ထွက်သွားပြီ / မအောင် (မှတ်တမ်းနဲ့)
- Dashboard: စုစုပေါင်း၊ ဒီလဝင်သူ၊ သက်တမ်းကုန်တော့မည့် စာရွက်၊ ဖုန်းမစစ်ရသေးသူ၊ မရရသေးတဲ့ ခေါ်ပေးခ
- ရှာဖွေ / Filter / Sort၊ ဖုန်းဆက် / SMS / LINE / HR ကို profile ပို့ခြင်း
- မူကြမ်း အလိုအလျောက်သိမ်း (app ပိတ်သွားလည်း မပျောက်)
- ရက်စွဲမှာ ထိုင်းနှစ် (၂၅၆၇) ရိုက်လည်း ခရစ်နှစ်ပြောင်းပေး
- **Admin (PIN နဲ့)**: ဌာန/ရာထူး/အဆိုင်း စာရင်းပြင် → form မှာ ချက်ချင်းပေါ်၊ မဖြည့်မနေရ အကွက် ဖွင့်/ပိတ်၊ ခေါ်ပေးခ ဖွင့်/ပိတ် + ပုံသေငွေ၊ သက်တမ်းသတိပေးရက်၊ ဘာသာ၊ PIN ပြောင်း၊ Excel (CSV) ထုတ်၊ Backup ထုတ်/ပြန်သွင်း၊ ဒေတာအားလုံးဖျက်၊ လုပ်ဆောင်ချက် မှတ်တမ်း

## ဒေတာ / လုံခြုံရေး
- ဒေတာ အားလုံး **ဖုန်းထဲမှာပဲ** (AsyncStorage) သိမ်းပါတယ်။ Server / internet မလိုပါ။ Permission မတောင်းပါ။
- ဖုန်းပျောက်ရင် ဒေတာပါ ပျောက်မှာမို့ Admin → Backup ကို မှန်မှန်ထုတ်ပြီး LINE Keep / Google Drive မှာ သိမ်းပါ။
- Admin PIN က ဖုန်းကိုင်ထားသူ ဆက်တင် မပြင်မိအောင် ကာထားရုံပါ — ဒေတာကို encrypt မလုပ်ထားပါ။
- APK ကို Expo ရဲ့ debug key နဲ့ sign ထားပါတယ် (ကိုယ်တိုင်သုံး / ဖြန့်ဖို့ အဆင်ပြေ၊ Play Store တင်ချင်ရင် ကိုယ်ပိုင် keystore လိုပါမယ်)။

## Developer
```
npm install
npx expo start          # Expo Go နဲ့ စမ်း
npm test                # logic + screen render test
```
Stack: Expo SDK 52, React Native 0.76, `@react-native-async-storage/async-storage`, Ionicons. Code အားလုံး `App.js` တစ်ဖိုင်ထဲမှာ။
